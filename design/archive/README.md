# Historical design archive

These are the pre-sweep plans and handoff notes, preserved with their original
section numbers for code comments and older discussions. Their status tables,
open-item lists and proposed behavior are historical; use
[`../implemented.md`](../implemented.md) for delivered behavior and
[`../outstanding.md`](../outstanding.md) for the only current backlog.

`pipeline-service/` holds the service's chunked plan (S0-S7) with its "As
built" notes, and `library-sync/worklist-feedback.md` the agreed F1-F5
design, both archived when the built behavior was consolidated on 2026-09-27.

Each archived file has a banner naming its former path. Relative Markdown
links were adjusted for this directory move. The active
[`library-sync-pipeline-plan.md`](../library-sync-pipeline-plan.md) maps the old
chunk numbers to the current documents.
